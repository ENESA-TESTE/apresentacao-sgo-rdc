# SGO RDC - Site de Apresentação

Site estático, sem banco de dados e sem credenciais.

## Testar no computador
Abra `index.html` no navegador.

## Publicar no Vercel
1. Crie um repositório no GitHub.
2. Envie `index.html`, `styles.css`, `script.js` e `README.md`.
3. No Vercel, clique em Add New > Project.
4. Importe o repositório.
5. Em Framework Preset, escolha Other.
6. Deixe Build Command e Output Directory vazios.
7. Clique em Deploy.
